Para maximizar, con evaluación actual 107, candidata 120 y T = 10, se obtiene 1 / (1 + exp((107 − 120) / 10)) = 0.7858349830, coherente con 0.78 de la tabla. La expresión de Metropolis exp((107 − 120) / 10) = 0.2725317930 no coincide con esa probabilidad. El límite logístico al aumentar T es 0.5, también declarado en la lámina 28.

Para minimizar la distancia del TSP se define Δ = L(vn) − L(vc). La fórmula de la lámina 27, invirtiendo la resta, queda p = 1 / (1 + exp(Δ / T)). La lámina 30 añade una condición anterior: si la candidata mejora estrictamente, se acepta siempre. En consecuencia, la regla completa coherente con ambas láminas es aceptar si Δ < 0; en otro caso, aceptar si u < 1 / (1 + exp(Δ / T)), con u uniforme en [0,1). Si Δ = 0, la probabilidad es 0.5. No conviene escribir Δ <= 0 como aceptación incondicional si se quiere conservar literalmente ese caso del material.

Para empeoramientos, la implementación numéricamente estable es `a = exp(-delta / T); p = a / (1 + a)` porque delta >= 0 y T > 0. Así no se intenta calcular una exponencial positiva enorme al enfriarse. Se conserva el mejor recorrido encontrado por separado del recorrido actual; un recorrido peor aceptado no debe reemplazar al mejor global salvo que realmente lo mejore.

Ejemplo para la minimización: cambiar una distancia 107 por 120 con T = 10 tiene Δ = 13 y p = 0.21416501696. Una mejora de 120 a 107 se acepta con certeza mediante la condición inicial, aunque la logística aislada daría 0.7858349830. Este detalle distingue el pseudocódigo completo de aplicar la logística a todas las propuestas.
